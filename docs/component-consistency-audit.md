Fecha: 27 de octubre de 2026. Alcance: frontend activo en `Frontend/src`; estado inicial de Git limpio.

ni nueva consulta/comparación con Figma. No modifica backend, contratos, permisos, dependencias ni datos.

## Pendientes y límites

- Decidir si los campos de contraseña de gestión deben incorporar Mostrar/Ocultar y si los avisos de
  perfil deben tener una única densidad. Existen variantes aprobadas; no se cambia su aspecto sin ese criterio.
- El guard conserva el alcance del patrón existente de captura de enlaces internos. No intercepta
  Atrás/Adelante del navegador ni toda navegación programática; `beforeunload` depende del navegador.
  Una protección universal del router requeriría otra tarea. La confirmación explícita de logout sigue
  siendo la única necesaria para esa acción, incluso si hay un borrador.
- Recuperación de contraseña, OAuth, gestión administrativa de módulos/ejercicios y reconocimiento
  LSV no existen en el frontend activo. No son regresiones ni inconsistencias hipotéticas a corregir.
- Las capturas comprueban las composiciones existentes, sin comparación nueva con Figma ni afirmación
  de identidad píxel a píxel, auditoría WCAG completa o soporte probado en todos los navegadores.

## Resultado de las verificaciones

Las pruebas de componentes usan transporte controlado en jsdom; las pruebas de navegador usan
Express, cookies/CSRF y PostgreSQL WASM reales en un entorno local efímero. El adaptador de imágenes
académico es un sustituto explícito de S3. Ninguna de esas pruebas acredita una integración remota.

| Control                              | Resultado                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pnpm verify`                        | Código 0: lint sin errores ni advertencias, formato, 121 pruebas frontend + 44 backend + 65 SQL/auth = 230 pruebas aprobadas; Prisma validate, build frontend, sintaxis backend y generación/compilación Prisma correctos. Formato comprobado de nuevo tras cerrar este registro.                                                                                                                                                                             |
| `pnpm academic:verify`               | Código 0: cinco usuarios creados desde formularios, edición y eliminación lógica, cinco reportes con imágenes, visor, resolución/reapertura, lectura/práctica manual tras recarga y 24 eventos de bitácora; 40 combinaciones responsive/tema; cero excepciones de runtime.                                                                                                                                                                                    |
| Revisión adicional Chrome            | Código 0 en la revisión final: 16 combinaciones de logout (ADMIN/USER × 1440/834/390/320 × claro/oscuro), foco inicial, Tab/Shift+Tab, Escape, restauración de foco/scroll, sesión conservada al cancelar y ocho cierres confirmados con revocación SQL. Perfil y reporte conservan el borrador al cancelar y descartan solo al confirmar; cero excepciones de runtime.                                                                                       |

La primera ejecución de Vitest fue bloqueada por `spawn EPERM` del sandbox; la ejecución autorizada
funcionó sin cambiar dependencias ni controles. La primera pasada agregada detectó formato pendiente;
se corrigió solo en archivos de la tarea. Los fixtures de pruebas se actualizaron al nuevo modal.
El controlador local de Chrome se ajustó para enviar teclas nativas, enfocar el disparador real y
distinguir sesiones de preparación de sesiones del navegador; esos fallos de instrumentación no se
presentan como regresiones del producto.
