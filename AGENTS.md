# Instrucciones para agentes de desarrollo

Antes de crear, modificar o revisar una lección educativa, consulta y cumple
[`docs/LESSON_DESIGN_STANDARD.md`](docs/LESSON_DESIGN_STANDARD.md). Ese documento es la fuente
oficial de arquitectura, diseño visual, pedagogía, progreso, accesibilidad y calidad para las
lecciones de VocesSilentes.

Si un cambio altera un componente compartido, un token o regla visual, la navegación, el progreso
o el comportamiento general de las lecciones, actualiza también ese estándar en el mismo cambio.
